MVS Explorer Toolkit Project Version History

0.3.0 - 2026-08-27
  - Added shared development-time libraries/templates and generator while
    preserving fully standalone public batch deliverables.
  - Regenerated 30 source-order scalar tools from injected common source.
  - Added 90 sorted scalar tools: every scalar print/read projection now has
    sorted_by_id, sorted_by_title, and sorted_by_date companions.
  - ID sort is numeric ascending.
  - Title sort is case-insensitive natural/alphanumeric with ID tie-break.
  - Date sort is chronological where parseable with deterministic tie-breaks.
  - Added 7 lookup tools.
  - Added exact and '*' wildcard lookup matching.
  - Multiple lookup matches are ordered by searched/source field.
  - Lookup output is distinct non-empty associated values, one per line.
  - Added development generator, validator, templates, common source, and
    tool specification.
  - Updated project documentation and development records.

0.2.0 - 2026-08-27
  - Reworked all scalar public batch files to be fully standalone.
  - Added development documentation, directives, histories, style addendum,
    embedded PowerShell guide, and observation journal.

0.1.0 - 2026-08-27
  - Initial scalar-product toolkit using a shared runtime parser.
