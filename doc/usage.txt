MVS Explorer Toolkit 0.3.0
Usage Summary

SCALAR SOURCE-ORDER
  print_mvs_dump_<fields>.bat dump-folder
  read_mvs_dump_<fields>.bat dump-folder

SCALAR SORTED
  print_mvs_dump_<fields>_sorted_by_id.bat dump-folder
  print_mvs_dump_<fields>_sorted_by_title.bat dump-folder
  print_mvs_dump_<fields>_sorted_by_date.bat dump-folder

  read_mvs_dump_<fields>_sorted_by_id.bat dump-folder
  read_mvs_dump_<fields>_sorted_by_title.bat dump-folder
  read_mvs_dump_<fields>_sorted_by_date.bat dump-folder

SORTS
  ID     numeric ascending
  TITLE  natural/alphanumeric ascending, case-insensitive; ID tie-break
  DATE   chronological ascending where parseable; date text then ID tie-break

LOOKUPS
  lookup_mvs_title_from_id.bat dump-folder search-value
  lookup_mvs_title_from_date.bat dump-folder search-value
  lookup_mvs_note_from_id.bat dump-folder search-value
  lookup_mvs_note_from_title.bat dump-folder search-value
  lookup_mvs_note_from_date.bat dump-folder search-value
  lookup_mvs_date_from_id.bat dump-folder search-value
  lookup_mvs_date_from_title.bat dump-folder search-value

LOOKUP WILDCARD
  * matches zero or more characters.
  Matching is case-insensitive.
  Every character other than * is literal.

EXAMPLES
  lookup_mvs_title_from_id.bat mvs_2021-08-17 28
  lookup_mvs_title_from_id.bat mvs_2021-08-17 2*
  lookup_mvs_title_from_id.bat mvs_2021-08-17 *28
  lookup_mvs_title_from_id.bat mvs_2021-08-17 *2*
  lookup_mvs_note_from_title.bat mvs_2021-08-17 "Windows 7 *"

LOOKUP OUTPUT
  One distinct non-empty associated value per line.
  Multiple matching rows are ordered by the searched/source field.
  No associated value: no stdout, return code 1.

DUMP RESOLUTION
  A dump may be an absolute/relative folder path or a dump folder name.
  Named folders are searched in the current directory, MVS_DUMPS_ROOT,
  the script directory, and common adjacent mvs_dumps_archive locations.
