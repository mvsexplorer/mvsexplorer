MVS Explorer Toolkit 0.5.0
Usage Summary

SCALAR SOURCE-ORDER
  print_mvs_dump_<fields>.bat dump-folder
  read_mvs_dump_<fields>.bat dump-folder

SCALAR SORTED
  print_mvs_dump_<fields>_sorted_by_id.bat dump-folder
  print_mvs_dump_<fields>_sorted_by_title.bat dump-folder
  print_mvs_dump_<fields>_sorted_by_date.bat dump-folder

  read_mvs_dump_<fields>_sorted_by_id.bat dump-folder
  read_mvs_dump_<fields>_sorted_by_title.bat dump-folder
  read_mvs_dump_<fields>_sorted_by_date.bat dump-folder

SORTS
  ID     numeric ascending
  TITLE  natural/alphanumeric ascending, case-insensitive; ID tie-break
  DATE   chronological ascending where parseable; date text then ID tie-break

LOOKUPS
  lookup_mvs_title_from_id.bat dump-folder search-value
  lookup_mvs_title_from_date.bat dump-folder search-value
  lookup_mvs_note_from_id.bat dump-folder search-value
  lookup_mvs_note_from_title.bat dump-folder search-value
  lookup_mvs_note_from_date.bat dump-folder search-value
  lookup_mvs_date_from_id.bat dump-folder search-value
  lookup_mvs_date_from_title.bat dump-folder search-value

LOOKUP WILDCARD
  * matches zero or more characters.
  Matching is case-insensitive.
  Every character other than * is literal.

EXAMPLES
  lookup_mvs_title_from_id.bat mvs_2021-08-17 28
  lookup_mvs_title_from_id.bat mvs_2021-08-17 2*
  lookup_mvs_title_from_id.bat mvs_2021-08-17 *28
  lookup_mvs_title_from_id.bat mvs_2021-08-17 *2*
  lookup_mvs_note_from_title.bat mvs_2021-08-17 "Windows 7 *"

LOOKUP OUTPUT
  One distinct non-empty associated value per line.
  Multiple matching rows are ordered by the searched/source field.
  No associated value: no stdout, return code 1.

DUMP RESOLUTION
  A dump may be an absolute/relative folder path or a dump folder name.
  Named folders are searched in the current directory, MVS_DUMPS_ROOT,
  the script directory, and common adjacent mvs_dumps_archive locations.


AUTOMATED TESTS
  From project root:

    test\test_all.bat path_to_mvs_dump_folder

  Subsets:

    test\test_structure.bat
    test\test_scalar_tools.bat path_to_mvs_dump_folder
    test\test_lookup_tools.bat path_to_mvs_dump_folder

  Return:
    0  all executed tests passed
    1  one or more tests failed
    2  invalid/missing required test argument


TEST RESULT DIRECTORY
  Every test invocation creates:

    test\test-results-YYYYMMDD-HHMMSS\

  Main files:
    README.txt
    run-info.txt
    console.log
    summary.txt
    all-results.tsv
    general-results.tsv
    structure-results.tsv
    scalar-results.tsv
    lookup-results.tsv
    failures\


DUPLICATE DIAGNOSTICS
  find_mvs_duplicate_<property>_in_<source>.bat dump-folder

  Properties currently covered:
    ID
    TITLE
    DATE
    FILENAME

  A successful scan returns 0 whether findings exist or not.
  No findings produce no stdout.

ORPHAN DIAGNOSTICS
  find_mvs_orphan_<property>_from_<source>_in_<target>.bat dump-folder

  The comparison is directional:
    each source occurrence is reported if the target lacks the same
    normalized property value.

DIAGNOSTIC OUTPUT
  mvs.txt / mvs_names.txt ID/title findings:
    duplicate/orphan key plus complete source section

  mvs.txt / mvs_names.txt filename findings:
    owner ID, owner title, exact matched checksum/filename line

  mvs_ids.txt / mvs_dates.txt:
    original source line

  mvs_notes.html:
    normalized title/note text; literal [ID: N] only when present

DIAGNOSTIC TEST
  test\test_diagnostic_tools.bat

FULL TEST
  test\test_all.bat path_to_real_mvs_dump_folder

  The full suite uses:
    real dump -> scalar and lookup regressions
    test\test-mvs-dump-diagnostics -> duplicate/orphan regressions


FILENAME RELATIONSHIP QUERY
  print_mvs_dump_<projection>_from_filename.bat dump-folder "filename"
  read_mvs_dump_<projection>_from_filename.bat dump-folder "filename"

HASH RELATIONSHIP QUERY
  print_mvs_dump_<projection>_from_hash.bat dump-folder hash
  read_mvs_dump_<projection>_from_hash.bat dump-folder hash

  HASH may be SHA-1 or SHA-256.
  Hash-to-filename sources:
    mvs.txt
    mvs.sha1
    mvs.sha256

  Filename/hash matching is exact and case-insensitive.

RELATIONSHIP RETURN CODES
  0  projected result emitted / help
  1  no associated projected result
  2  invalid or missing argument/configuration
  3  dump folder not found
  4  required mvs.txt missing
  5  parse/runtime failure
