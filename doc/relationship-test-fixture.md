# Relationship Synthetic Test Dump

Location:

```text
test\test-mvs-dump-relationships\
```

This fixture is intentionally synthetic.

It is designed to prove the complete filename/hash traversal independently of
the real dump used by scalar/lookup regression.

Designed cases:

- `shared.iso` is owned by two different `mvs.txt` product IDs;
- the primary SHA-1 test hash exists only in `mvs.sha1`;
- the primary SHA-256 test hash exists only in `mvs.sha256`;
- a separate tested SHA-1 exists only on an `mvs.txt` filename line;
- manifest-only filenames exist for future orphan relationship cases;
- product dates and notes are present so every requested projection has
  non-empty positive test data.

Fixed expected stdout lives under:

```text
test\expected-relationships\
```

It is generated by:

```text
dev\generate_expected_relationship_outputs.py
```

That generator is a separate Python reference implementation and never invokes
the public `.bat` files under test.

Relationship-only test command:

```text
test\test_relationship_tools.bat
```

Full suite:

```text
test\test_all.bat path_to_real_mvs_dump_folder
```

The relationship suite performs:

```text
48 filename-query behavior cases
96 hash-query behavior cases:
   each of 48 hash tools with SHA-1 and SHA-256
2 additional mvs.txt-only hash-source cases
4 no-result return-code cases
1 fixture-presence assertion
---
151 relationship assertions
```
