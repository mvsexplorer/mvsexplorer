MVS Explorer Toolkit 0.1.0
Scalar Product Views

USAGE
  <script>.bat dump-folder
  <script>.bat --help

EXAMPLES
  print_mvs_dump_id.bat mvs_2021-08-17
  print_mvs_dump_id_title_date.bat mvs_2021-06-21-1830
  read_mvs_dump_id_title.bat "D:\MVS\mvs_2021-08-17"
  read_mvs_dump_title_note.bat mvs_2021-08-17 > titles-and-notes.tsv

OUTPUT MODES
  print_  Human-readable. One line per product. Fields have labels and are
          separated by " | ". Missing values are shown as "(none)".

  read_   Machine-readable TSV. One line per product. No header, colors,
          banner, or other decoration. Missing values are empty fields.

SCALAR FIELD ORDER
  Field order follows the script name.

  read_mvs_dump_id_title_date:
      ID<TAB>TITLE<TAB>DATE

  read_mvs_dump_title_date_note:
      TITLE<TAB>DATE<TAB>NOTE

DUMP RESOLUTION
  The argument may be an absolute/relative path to the dump folder or a
  folder name such as mvs_2021-08-17.

  Named dump folders are searched in the current directory, MVS_DUMPS_ROOT,
  the toolkit directory, and common mvs_dumps_archive locations adjacent to
  the toolkit/current directory.

REQUIRED SOURCE FILES
  mvs_ids.txt
  mvs_dates.txt

OPTIONAL SOURCE FILE
  mvs_notes.html

NOTE JOIN POLICY
  Notes are keyed by title in mvs_notes.html, not by ID. Exact normalized
  title matches are used. Multiple distinct note blocks for the same title
  are joined with " || ". Duplicate IDs are not present in the supplied
  snapshots, but duplicate titles across different IDs do occur.

RETURN CODES
  0  success/help
  2  invalid arguments/mode/field
  3  dump folder not found
  4  required source file missing
  5  no products parsed
